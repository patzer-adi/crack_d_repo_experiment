# Reports Directory

Implementation reports are stored here. Each report corresponds to a plan
with the same serial number.

See `AGENT_MD/plan/rules.md` for the report template and naming conventions.

> **To create a new report:** copy `REPORT-000_template.md` to `REPORT-NNN_slug.md`
> where NNN matches the plan being closed.

| Report | Plan | Status |
|--------|------|--------|
| `REPORT-000_template.md` | — | Template — do not rename or delete |
| | | _Add new rows above this line_ |
