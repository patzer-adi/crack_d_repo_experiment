Spiral Matrix

LC #54 Medium Array

Before you code

Clarifying questions to ask first

Ask these before writing anything. Each answer constrains what the solution needs to handle.

What if the matrix has only one row or column?
The algorithm naturally handles it. All elements lie on a single boundary, so the remaining boundaries collapse immediately.
→ No special case needed; boundary shrinking subsumes m=1 or n=1.
What is "spiral order"?
Clockwise from the outside in: top row left-to-right, right column top-to-bottom, bottom row right-to-left, left column bottom-to-top. Repeat for inner layers.
→ Four directional passes per layer, shrinking boundaries after each.
What if m=0 or n=0 (empty matrix)?
Return an empty list.
→ Early termination; no elements to traverse.
How do we avoid revisiting elements?
After each directional pass, shrink the corresponding boundary inward. When boundaries cross (top > bottom or left > right), stop.
→ Boundary shrinking prevents overlap between passes.

The Insight

Shrink four boundaries inward; the spiral walks the perimeter of what's left.

Watch the algorithm from the perspective of the unvisited region. Four integers (top, bottom, left, right) bracket it. Each directional pass walks one edge of that region, then peels the edge away by moving its boundary inward. The next pass walks the next edge of the now-smaller rectangle. Boundaries crossing means done.

The kernel

Step 1

Brute force — feel the cost

Track which cells have been visited in a separate boolean matrix. Walk in the current direction; if the next cell is out of bounds or already visited, rotate 90°. Same output, but O(m×n) extra space just to remember where we've been. Step through to see why shrinking the active region (the optimal approach) eliminates the visited matrix entirely.

pos = (—, —)  ·  dir = —  ·  visited cells: 0

Cost: O(m×n) time + O(m×n) extra space

Each cell is visited exactly once (O(mn) time, same as optimal), but the visited matrix burns O(mn) extra memory. The boundary-shrinking approach below pays O(1) extra space — just four ints.

vector<int> spiralOrder(vector<vector<int>>& matrix) {
    vector<int> result;
    if (matrix.empty()) return result;
    int m = matrix.size(), n = matrix[0].size();
    vector<vector<bool>> visited(m, vector<bool>(n, false));
    int dirs[4][2] = {{0,1}, {1,0}, {0,-1}, {-1,0}};
    int d = 0, i = 0, j = 0;
    for (int cnt = 0; cnt < m * n; cnt++) {
        result.push_back(matrix[i][j]);
        visited[i][j] = true;
        int ni = i + dirs[d][0], nj = j + dirs[d][1];
        if (ni < 0 || ni >= m || nj < 0 || nj >= n || visited[ni][nj]) {
            d = (d + 1) % 4;
            ni = i + dirs[d][0]; nj = j + dirs[d][1];
        }
        i = ni; j = nj;
    }
    return result;
}

Step 2

Translations — every optimisation, named

The optimization from visited-array to boundary-shrinking eliminates the O(m×n) extra space. Instead of marking cells, we track the active boundaries and shrink them after each directional pass. This is the only optimization we need—the algorithm is already optimal.

1
Visited-array approach
Track visited cells in a separate 2D boolean array. Rotate direction when hitting a boundary or visited cell.
O(m×n) time, O(m×n) space (visited array)
2
4-boundary pointers (taught)
Maintain top, bottom, left, right boundaries. After each directional pass, shrink the boundary inward. No visited array needed.
O(m×n) time, O(1) space

Step 3

The algorithm in plain English

1
Initialize top=0, bottom=m−1, left=0, right=n−1, and an empty result list.
2
While top ≤ bottom and left ≤ right (boundaries have not crossed):
3
Traverse top row left-to-right (j: left → right). Append matrix[top][j]. Then top++.
4
Traverse right column top-to-bottom (i: top → bottom). Append matrix[i][right]. Then right−−.
5
If top ≤ bottom, traverse bottom row right-to-left (j: right → left). Append matrix[bottom][j]. Then bottom−−.
6
If left ≤ right, traverse left column bottom-to-top (i: bottom → top). Append matrix[i][left]. Then left++.
7
Return the result list.

Step 4

Code

vector<int> spiralOrder(vector<vector<int>>& matrix) {
    vector<int> result;
    if (matrix.empty()) {
        return result;
    }
    int m = matrix.size();
    int n = matrix[0].size();
    int top = 0, bottom = m - 1, left = 0, right = n - 1;
    while (top <= bottom && left <= right) {
        // Top row
        for (int j = left; j <= right; j++) {
            result.push_back(matrix[top][j]);
        }
        top++;
        // Right column
        for (int i = top; i <= bottom; i++) {
            result.push_back(matrix[i][right]);
        }
        right--;
        // Bottom row (if exists)
        if (top <= bottom) {
            for (int j = right; j >= left; j--) {
                result.push_back(matrix[bottom][j]);
            }
            bottom--;
        }
        // Left column (if exists)
        if (left <= right) {
            for (int i = bottom; i >= top; i--) {
                result.push_back(matrix[i][left]);
            }
            left++;
        }
    }
    return result;
}

Step 7

Corner cases

1
Single element [[1]]
top=0, bottom=0, left=0, right=0. Top row: append 1; top=1. Loop exits (top > bottom). Return [1].
2
Single row [[1,2,3]]
top=0, bottom=0. Top row: append 1,2,3; top=1. Loop exits (top > bottom). Return [1,2,3].
3
Single column [[1],[2],[3]]
left=0, right=0. All three elements are encountered in the top row (i loop) and right column (j loop) phases. The bottom/left phases skip due to boundary checks.
4
2×2 [[1,2],[3,4]]
Top row: 1,2 (top=1). Right column: 4 (right=0). Bottom row check (top ≤ bottom): yes, append 3; bottom=0. Left column check (left ≤ right): no (0 > 0), skip. Return [1,2,4,3].
5
Empty matrix []
m=0, so the loop condition top ≤ bottom (0 ≤ -1) is false on first check. Return [].

Step 8

Production readiness

✓
Empty matrix: Early return if matrix is empty (m=0 or n=0).
✓
Single row/column: Boundary shrinking naturally handles m=1 or n=1.
✓
Boundary guards: Check top ≤ bottom and left ≤ right before bottom and left passes to prevent double-appending.
✓
Loop termination: Loop exits when top > bottom OR left > right.
✓
Shrinking order: top++, right--, bottom--, left++. Increment/decrement after each directional pass.
✓
Time complexity: O(m×n); every cell is visited exactly once.
✓
Space complexity: O(1) auxiliary; result vector is output.

Step 9

Approaches — trade-offs

O(m×n) O(1)

Maintain four pointers (top, bottom, left, right) and traverse in four directions per layer. After each pass, shrink the boundary. Clear, easy to debug, and the most common interview approach.

vector<int> spiralOrder(vector<vector<int>>& matrix) {
    vector<int> result;
    if (matrix.empty()) return result;
    int m = matrix.size(), n = matrix[0].size();
    int top = 0, bottom = m - 1, left = 0, right = n - 1;
    while (top <= bottom && left <= right) {
        for (int j = left; j <= right; j++)
            result.push_back(matrix[top][j]);
        top++;
        for (int i = top; i <= bottom; i++)
            result.push_back(matrix[i][right]);
        right--;
        if (top <= bottom) {
            for (int j = right; j >= left; j--)
                result.push_back(matrix[bottom][j]);
            bottom--;
        }
        if (left <= right) {
            for (int i = bottom; i >= top; i--)
                result.push_back(matrix[i][left]);
            left++;
        }
    }
    return result;
}
O(m×n) O(m×n)

Recursively extract the outer layer (top row, right column, bottom row, left column), then call yourself on the inner (m−2)×(n−2) submatrix. Same time complexity but uses the call stack for state. Less intuitive and slightly slower due to function overhead.

void spiralHelper(vector<vector<int>>& matrix, int t, int b, int l, int r, vector<int>& result) {
    if (t > b || l > r) return;
    for (int j = l; j <= r; j++) result.push_back(matrix[t][j]);
    for (int i = t + 1; i <= b; i++) result.push_back(matrix[i][r]);
    if (t < b) for (int j = r - 1; j >= l; j--) result.push_back(matrix[b][j]);
    if (l < r) for (int i = b - 1; i > t; i--) result.push_back(matrix[i][l]);
    spiralHelper(matrix, t + 1, b - 1, l + 1, r - 1, result);
}
vector<int> spiralOrder(vector<vector<int>>& matrix) {
    vector<int> result;
    if (matrix.empty()) return result;
    spiralHelper(matrix, 0, matrix.size() - 1, 0, matrix[0].size() - 1, result);
    return result;
}
