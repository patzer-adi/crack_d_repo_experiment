Clarifying questions to ask first

Ask these before writing anything. Each answer constrains what the solution needs to handle.

Which characters should we ignore?

Non-alphanumeric characters only: letters and digits count. Spaces, punctuation, symbols are ignored.

→ Can skip ahead without storing; only compare alphanumeric chars

Is comparison case-sensitive?

No. 'A' and 'a' are treated as identical.

→ Normalize each character on-the-fly; no pre-processing needed

What if the string has only non-alphanumeric characters?

It is a valid palindrome (vacuously true).

→ After filtering, an empty string is a palindrome

Can we use O(n) extra space?

Better not to. A clean solution skips non-alphanumeric in-place with O(1) space.

→ Two pointers advance inward; no cleaned copy needed

Assumptions we carry forward

The input is a string of printable ASCII characters (letters, digits, spaces, punctuation). We ignore case and non-alphanumeric characters. Empty strings and single characters are valid palindromes. We return a boolean: true if the string (after filtering and normalization) reads the same forwards and backwards, false otherwise.

The Insight

Two pointers squeeze from both ends, comparing only alphanumeric characters.

A palindrome reads the same forwards and backwards — so a string of length n is a palindrome iff s[i] equals s[n−1−i] for every i. Two pointers walking inward from both ends test exactly that pairing, one comparison at a time. Non-alphanumeric characters are skipped in place by advancing the relevant pointer past them; no cleaned copy is ever built.

The kernel

Initialize left=0 and right=n−1. Loop while left < right: skip non-alphanumeric characters by incrementing left and decrementing right. At each step, compare s[left].lower() with s[right].lower(). If they differ, return false. If they match, advance both pointers. If pointers meet or cross, return true. This works in O(n) time with O(1) auxiliary space.

Step 1

Brute force: clean first, then compare

Create a new string containing only alphanumeric characters (lowercased). Then check if this cleaned string equals its reverse. Two passes: one to build the cleaned string, one to compare.

One pass to build the cleaned string, one to reverse, one to compare. Auxiliary space needed for the cleaned copy.

bool isPalindrome_BF(string s) {
    string cleaned = "";
    for (char c : s) {
        if (isalnum(c)) {
            cleaned += tolower(c);
        }
    }
    string rev = cleaned;
    reverse(rev.begin(), rev.end());
    return cleaned == rev;
}

Step 3

The algorithm in plain English

1
Initialize left = 0, right = length(s) − 1.
2
Loop while left < right.
3
Skip non-alphanumeric: increment left while s[left] is not alphanumeric.
4
Skip non-alphanumeric: decrement right while s[right] is not alphanumeric.
5
Compare s[left].lower() and s[right].lower(). If not equal, return false.
6
Advance left++, right−−. Continue loop.
7
Return true if loop completes without a mismatch.

Step 4

Code

bool isPalindrome(string s) {
    int left = 0, right = s.length() - 1;
    while (left < right) {
        while (left < right && !isalnum(s[left])) {
            left++;
        }
        while (left < right && !isalnum(s[right])) {
            right--;
        }
        if (tolower(s[left]) != tolower(s[right])) {
            return false;
        }
        left++;
        right--;
    }
    return true;
}

Step 7

Corner cases

1
Empty string
Input: "". No characters; left=0, right=−1; loop doesn't run. Return true.
2
Single character
Input: "a". left=0, right=0; left < right is false; loop doesn't run. Return true.
3
All non-alphanumeric
Input: "!@#$%". Both pointers skip to out-of-bounds; loop exits. Return true.
4
Mixed case
Input: "Aa". left='A'→'a', right='a'; they match after normalization. Return true.
5
Mismatch at edges
Input: "ab". left='a', right='b'; no match. Return false immediately.

Step 9

Approaches — trade-offs

O(n) O(1)

Maintain left and right pointers. Skip non-alphanumeric characters at each end. Compare normalized characters on-the-fly. No modification of input; no auxiliary storage. This is the optimal solution.

bool isPalindrome(string s) {
    int left = 0, right = s.length() - 1;
    while (left < right) {
        while (left < right && !isalnum(s[left])) left++;
        while (left < right && !isalnum(s[right])) right--;
        if (tolower(s[left]) != tolower(s[right])) return false;
        left++; right--;
    }
    return true;
}
O(n) O(n)

Build a cleaned, lowercased string by iterating through and keeping only alphanumeric characters. Then check if this string equals its reverse. Simple and intuitive, but uses O(n) space for the cleaned copy.

bool isPalindrome(string s) {
    string cleaned;
    for (char c : s) {
        if (isalnum(c)) cleaned += tolower(c);
    }
    string rev = cleaned;
    reverse(rev.begin(), rev.end());
    return cleaned == rev;
}
O(n) O(n)

Use regex to remove all non-alphanumeric characters, convert to lowercase, then compare with reversed string. Concise in languages with strong regex support (Python, JavaScript), but slightly slower due to regex compilation.

// Python example:
import re
def isPalindrome(s: str) -> bool:
    cleaned = re.sub(r'[^a-zA-Z0-9]', '', s).lower()
    return cleaned == cleaned[:-1]
