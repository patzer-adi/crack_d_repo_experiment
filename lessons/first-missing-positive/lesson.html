First Missing Positive

LC #41 Hard Array

Before you code

Clarifying questions to ask first

Ask these before writing anything. Each answer constrains what the solution needs to handle.

What is the range of possible answers?
The answer is always in [1, n+1]. If all numbers 1 through n are present, the answer is n+1. Otherwise, the answer is the smallest missing positive.
→ The answer range bounds the problem; we only need to check n+1 possibilities.
What if the array has duplicates?
Duplicates don't change the set of present positives. We only care about presence, not count.
→ We can collapse duplicates into a single "present" marker.
Can we use extra space?
A hash set works (O(n) space). But we can do better: use the array itself as the hash table.
→ In-place marking trades modification for O(1) space.
How can the array index encode the value?
For a value k in [1, n], place it at index k-1. Then the presence of k is marked by the value at index k-1.
→ Array indices [0, n-1] encode values [1, n] directly.

The Insight

Pigeonhole: with n slots and n+1 possible answers, place each value at its home index.

The answer is always in [1, n+1]. We have exactly n slots and care about exactly n values (1 through n) — a perfect pigeonhole. Use index k−1 as the home for value k. Swap each in-range value to its home, then scan: the first index whose value doesn't match its home is the answer.

current i at home (nums[i] = i+1) out of [1, n] ↔ swap pair
phase: — answer = —

The kernel

for each i: while nums[i] ∈ [1, n] and nums[nums[i]−1] ≠ nums[i]: swap nums[i] ↔ nums[nums[i]−1]
then scan: return first i+1 where nums[i] ≠ i+1, else n+1
O(n) total swaps amortised — each swap places at least one value at home, and once placed it never moves again. O(1) extra space.

Step 1

Brute force — feel the cost

For each candidate k from 1 to n+1, scan the entire array to check if k is present. The first candidate that is missing is the answer. Two nested loops over up to n+1 candidates and n values — O(n²) time, O(1) space. Step through to see why a fast in-place approach beats this on every example.

candidate = —  ·  scanning index = —  ·  checks: 0

Cost: O(n²) time, O(1) space

For each candidate k ∈ [1, n+1], scan up to n values. Worst case is roughly n(n+1) comparisons. The optimal cyclic-sort approach below pays one O(n) pass instead.

int firstMissingPositive_BF(vector<int>& nums) {
    int n = nums.size();
    for (int k = 1; k <= n + 1; k++) {
        bool found = false;
        for (int v : nums) {
            if (v == k) { found = true; break; }
        }
        if (!found) return k;
    }
    return n + 1;
}

Step 2

Translations — every optimisation, named

The optimization from O(n²) brute force to O(n) in-place uses the array itself as a hash table. Instead of searching for each candidate, we mark presence by placing numbers at their home indices, then scan once to find the first missing.

1
Brute force with search
For each candidate [1, n+1], scan the entire array to check if it exists.
O(n²) time, O(1) space
2
Hash set
Store all positive integers in a set. Scan [1, n+1] to find the first missing.
O(n) time, O(n) space
3
Array as hash table (taught)
Use array indices to mark presence via swapping numbers to home indices. Scan array to find the first wrong value.
O(n) time, O(1) space

Step 3

The algorithm in plain English

1
First pass (place numbers): Iterate through the array. For each number num, if 1 ≤ num ≤ n and it's not in its home index (nums[num-1] ≠ num), swap nums[i] with nums[num-1]. Repeat until the current element is either in place or out of range.
2
Second pass (find missing): Iterate through indices [0, n-1]. If nums[i] ≠ i+1, return i+1 (the first missing positive).
3
Default: If all indices [0, n-1] have correct values, return n+1.

Step 4

Code

int firstMissingPositive(vector<int>& nums) {
    int n = nums.size();
    // First pass: place each number at its home index
    for (int i = 0; i < n; i++) {
        while (1 <= nums[i] && nums[i] <= n && nums[nums[i] - 1] != nums[i]) {
            // Swap nums[i] with nums[nums[i] - 1]
            int home_idx = nums[i] - 1;
            swap(nums[i], nums[home_idx]);
        }
    }
    // Second pass: find the first missing positive
    for (int i = 0; i < n; i++) {
        if (nums[i] != i + 1) {
            return i + 1;
        }
    }
    return n + 1;
}

Step 7

Corner cases

1
All in place [1, 2, 3, 4]
All numbers are already at their home indices. No swaps needed. Scan finds all correct; return n+1=5.
2
Missing first [2, 3, 4]
Swap 2 to index 1, 3 to index 2, 4 to index 3. Index 0 should have 1 but has -1 (out of range). Return 1.
3
Duplicates [1, 1, 1]
First 1 goes to index 0. Other 1's stay (already correct value at home). Index 1 should have 2 but has 1. Return 2.
4
All out of range [10, 11, 12]
No numbers in [1, n]. No swaps. Index 0 should have 1 but has 10. Return 1.
5
Negatives and zeros [0, -1, 3, 4]
Swap 3 and 4 to their homes. Indices 0 and 1 don't have 1 and 2. Index 0 should have 1 but has 0. Return 1.

Step 8

Production readiness

✓
Swap condition: Verify 1 ≤ nums[i] ≤ n before accessing nums[nums[i]-1].
✓
Avoid infinite swaps: Check nums[nums[i]-1] != nums[i] to avoid swapping the same value infinitely.
✓
Duplicate handling: If nums[i] and nums[nums[i]-1] are the same, don't swap; skip to next iteration.
✓
First pass termination: While loop terminates when nums[i] is out of range or already at home.
✓
Second pass correctness: Return i+1 on first mismatch; if all match, return n+1.
✓
Time complexity O(n): Each number is moved at most once; overall n swaps + 2 passes = O(n).

Step 9

Approaches — trade-offs

O(n) O(1)

Place numbers at their home indices via swapping. Mark presence implicitly. Scan to find the first wrong value. Optimal space and time, but modifies the input.

int firstMissingPositive(vector<int>& nums) {
    int n = nums.size();
    for (int i = 0; i < n; i++) {
        while (1 <= nums[i] && nums[i] <= n && nums[nums[i] - 1] != nums[i]) {
            int home_idx = nums[i] - 1;
            swap(nums[i], nums[home_idx]);
        }
    }
    for (int i = 0; i < n; i++) {
        if (nums[i] != i + 1) {
            return i + 1;
        }
    }
    return n + 1;
}
O(n) O(n)

Store all positive integers in a hash set. Iterate [1, n+1] and return the first number not in the set. Simple and clear, but uses O(n) extra space.

int firstMissingPositive(vector<int>& nums) {
    unordered_set<int> seen;
    for (int num : nums) {
        if (num > 0) seen.insert(num);
    }
    for (int candidate = 1; candidate <= nums.size() + 1; candidate++) {
        if (!seen.count(candidate)) {
            return candidate;
        }
    }
    return nums.size() + 1;
}
O(n²) O(1)

For each candidate [1, n+1], scan the array to check if it exists. Slow but simple. Use only when n is very small.

int firstMissingPositive(vector<int>& nums) {
    int n = nums.size();
    for (int candidate = 1; candidate <= n + 1; candidate++) {
        bool found = false;
        for (int num : nums) {
            if (num == candidate) {
                found = true;
                break;
            }
        }
        if (!found) return candidate;
    }
    return n + 1;
}
