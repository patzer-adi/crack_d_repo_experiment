Number of Islands

LC #200 Medium Graphs — BFS / DFS

Before you code

Clarifying questions to ask first

Ask these before writing anything. Each answer constrains what the solution needs to handle.

What counts as "adjacent" — do diagonals connect?
Only the four orthogonal neighbours (up/down/left/right). A diagonal touch does not join two cells.
→ a 4-direction neighbour helper, never 8
May I modify the input grid?
Usually yes — sinking each visited land cell to '0' is the cleanest "visited" marker. If mutation is banned, keep a separate visited matrix.
→ sink in place, or a parallel visited grid
Can the grid be empty, and how large?
It can have 0 rows (→ 0 islands); otherwise up to roughly 300×300. One linear pass is plenty.
→ guard grid.empty() before reading row 0
Are the cells chars or ints?
LeetCode passes '1'/'0' as chars, not integers.
→ compare against the character '1'

The Insight

Each island is discovered once — at the first cell you meet, then sunk so it can't be recounted

You kept meeting the same island from different cells and recounting it. The fix is bookkeeping, not cleverness: sweep the grid in reading order, and the first time you land on a cell no earlier flood has claimed, it has to be a new island — count it once, then flood-fill its whole body to water so every later step in the sweep walks right over it.

water land — not yet claimed flooding now (this island) claimed island (its number) scan cursor
Every cell the scan reaches is one of three things:
·
Water — skip it
A '0' cell is not land; the scan just moves on. Water never starts or joins an island.
+1
Unclaimed land — a NEW island
Land that no earlier flood has touched can only be the first cell of an island the scan hasn't seen. Add one to the count, then flood-fill outward to claim every cell connected to it.
∎
Already-claimed land — ignore it
Because the flood sank every cell it reached, land we meet again is already part of a counted island. The "sink on visit" step is exactly what stops the double-count.

The kernel

Scan every cell in row-major order. Skip water and land that is already sunk. When you hit unclaimed land, increment the island counter, then flood-fill (DFS/BFS) the whole connected blob, sinking each cell to water as you go so it is never visited again. Because a flood claims an entire island the moment its first cell is found, the counter advances exactly once per island — the answer is the number of times the scan had to start a fresh flood.

Step 1

Brute force — feel the cost

Suppose you never thought of the sink trick. How would you even group connected land? Give every land cell its own id, then repeatedly sweep the grid letting each cell copy the smallest id among its orthogonal land neighbours — keep sweeping until a whole pass changes nothing. At the end, cells in the same island share one id, so the number of distinct ids is the island count. It works, but each sweep re-scans the entire grid, and a snake-shaped island needs as many sweeps as it is long → O((m·n)²). Watch the sweep and cell-update counters climb.

sweeps: 0 cell-updates: 0 distinct ids (islands): 0

Cost: O((m·n)²) time, O(m·n) space

Every sweep re-touches all m·n cells, and the number of sweeps grows with the longest island's diameter — up to m·n on a snake. The labels do converge, but the repeated full re-scans are the waste the flood-fill avoids by claiming each island in one shot.

int numIslands(vector<vector<char>>& grid) {
    int m = grid.size(), n = grid[0].size();
    vector<vector<int>> id(m, vector<int>(n, 0));
    for (int r = 0; r < m; r++) {
        for (int c = 0; c < n; c++) {
            if (grid[r][c] == '1') { id[r][c] = r*n + c + 1; }
        }
    }
    int dr[] = {1,-1,0,0}, dc[] = {0,0,1,-1};
    bool changed = true;
    while (changed) {                       // re-sweep until stable
        changed = false;
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (id[r][c] == 0) { continue; }
                for (int d = 0; d < 4; d++) {
                    int nr = r+dr[d], nc = c+dc[d];
                    if (nr<0||nr>=m||nc<0||nc>=n||id[nr][nc]==0) { continue; }
                    if (id[nr][nc] < id[r][c]) { id[r][c] = id[nr][nc]; changed = true; }
                }
            }
        }
    }
    set<int> labels;                        // distinct ids = islands
    for (auto& row : id) for (int v : row) if (v) labels.insert(v);
    return labels.size();
}

Step 2

Translations — every optimisation, named

Three swaps turn the repeated re-labelling sweeps into a single linear pass.

1
"Which island is this cell in?" → "Is this the first cell of a new island?"
Stop asking each cell for its component. Decide membership by sinking on visit: the only cell that starts a new count is the first one the scan meets in an unclaimed island.
drops the repeated re-grouping
2
Re-scanning settled land → sink each cell once
Flood-fill turns every claimed land cell into water (or marks it visited). Settled regions are never walked again, so each cell is touched a constant number of times.
O((m·n)²) → O(m·n)
3
"Count distinct labels" → "count flood starts"
No set of ids to deduplicate at the end. Each island is discovered exactly once, so a single counter incremented at every fresh flood already is the answer.
O(1) bookkeeping, no post-processing

Step 3

The algorithm in plain English

1
Scan every cell row by row, keeping a count that starts at 0.
2
Skip anything that is not land — water, and land already sunk by an earlier flood.
3
Discover. On unclaimed land, do count++ — this cell is the first of a new island.
4
Flood-fill the island: push the cell on a stack, sink it, and keep sinking every orthogonal land neighbour until the stack empties. The whole connected blob becomes water.
5
Return count once the scan ends — it is the number of floods you started, i.e. the number of islands.

Step 4

Code

int numIslands(vector<vector<char>>& grid) {
    int m = grid.size(), n = grid[0].size();
    int count = 0;
    int dr[] = {1,-1,0,0}, dc[] = {0,0,1,-1};
    for (int r = 0; r < m; r++) {
        for (int c = 0; c < n; c++) {
            if (grid[r][c] != '1') { continue; }
            count++;                          // new island discovered
            stack<pair<int,int>> st;
            st.push({r, c}); grid[r][c] = '0';     // seed + sink
            while (!st.empty()) {
                auto [cr, cc] = st.top(); st.pop();
                for (int d = 0; d < 4; d++) {
                    int nr = cr+dr[d], nc = cc+dc[d];
                    if (nr<0||nr>=m||nc<0||nc>=n||grid[nr][nc] != '1') { continue; }
                    grid[nr][nc] = '0';            // sink so it is not recounted
                    st.push({nr, nc});
                }
            }
        }
    }
    return count;
}

Step 7

Corner cases

1
Empty grid or all water
[] or [[0,0],[0,0]]: the scan finds no land, so no flood ever starts and count stays 0. Guard grid.empty() before reading grid[0].size().
2
All land
[[1,1],[1,1]]: the very first cell starts one flood that sinks the whole grid, so the rest of the scan finds only water. Answer: 1.
3
Diagonals don't connect
[[1,0],[0,1]]: the two 1s touch only at a corner, which the 4-direction helper ignores. They are two separate islands → 2, not 1.
4
Single row or column
[[1,1,0,1,1]]: the flood ripples left/right along the line; out-of-row neighbours are just bounds-rejected. Two runs of land → 2 islands.
5
One giant snake island
A single island winding through all m·n cells gives a recursion depth of m·n with recursive DFS — enough to overflow the call stack on a 300×300 grid. Prefer the iterative stack/queue flood shown here.

Step 8

Production readiness

✓
Guard the empty grid (m == 0) before reading grid[0].size() — otherwise indexing row 0 is undefined behaviour.
✓
Bounds-check all four neighbours before indexing — an out-of-range read is undefined behaviour in C++.
✓
Sink land the moment you visit it (set it to '0') so it can never be enqueued or counted twice. Use a separate visited matrix only if the input must stay intact.
✓
Increment count exactly once per island — at discovery, before the flood — never inside the flood loop.
✓
Prefer an explicit stack/queue over recursion for large grids; a single snake island can recurse m·n deep and blow the call stack.
✓
Compare against the character '1', not the integer 1 — the grid holds chars.

Step 9

Approaches — trade-offs

O(m·n)O(m·n)

The solution shown: scan, and on each fresh land cell flood the island with an explicit stack (DFS) or queue (BFS), sinking as you go. One pass, linear, and the explicit container removes any recursion-depth risk. This is the safe default for large grids.

O(m·n)O(m·n) stack

The most idiomatic and shortest version: a recursive dfs that sinks the current cell and calls itself on the four neighbours. Identical complexity, but the call stack can reach depth m·n on one snaking island — fine for interview-size grids, risky for the largest inputs.

void dfs(vector<vector<char>>& g, int r, int c) {
    int m = g.size(), n = g[0].size();
    if (r<0||r>=m||c<0||c>=n||g[r][c] != '1') { return; }
    g[r][c] = '0';                       // sink, then recurse
    dfs(g, r+1, c); dfs(g, r-1, c);
    dfs(g, r, c+1); dfs(g, r, c-1);
}
// numIslands: for each '1', count++ then dfs(g, r, c);
O(m·n·α)O(m·n)

Treat each land cell as a node and union it with its right and down land neighbours; the number of islands is the number of distinct roots. The inverse-Ackermann α is effectively constant. Heavier to write, but it shines when the grid changes over time — e.g. Number of Islands II, where cells are added one at a time and you want the running count.

// id(r,c) = r*n + c; parent[] sized m*n, each its own root.
// islands = number of land cells.
// for each land cell, for its right and down land neighbour:
//     if union(a, b) merged two sets: islands--;
// answer = islands.

Step 10

Complexity

Time
O(m·n)
Each cell is scanned once and sunk at most once; its four neighbours are inspected a constant number of times.
Space
O(m·n)
The stack or queue can hold up to every cell in the worst case — a grid that is one big island.
