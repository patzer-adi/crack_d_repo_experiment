Binary Search

Foundational Algorithms Tier 1 LC #704
Section 1

Explain the algorithm in plain English

Binary Search is the moment where sorted order starts paying rent. Instead of scanning every single value linearly, we keep an active boundary of possible indices and inspect the midpoint. Since the collection is sorted, this single midpoint check tells us which half of the boundaries can be permanently discarded.

Is the array sorted?
Yes, non-decreasing order. If not sorted, Binary Search cannot be applied.
→ unlocks: compare against the middle and discard half the range
What if the target is absent?
Return -1.
→ unlocks: loop while left <= right, otherwise exit and return -1

The kernel

Maintain the invariant that the target, if it exists, is always within the closed interval [left, right]. At each iteration, examine the middle element mid = left + (right - left) / 2. If it matches target, return mid. If it is smaller, search the right half by setting left = mid + 1. If it is larger, search the left half by setting right = mid - 1. When left > right, return -1.

Section 5

C++ code

int binarySearch(const vector<int>& nums, int target) {
    int left = 0;
    int right = static_cast<int>(nums.size()) - 1;

    while (left <= right) {
        int mid = left + (right - left) / 2;

        if (nums[mid] == target) {
            return mid;
        }

        if (nums[mid] < target) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }

    return -1;
}

Section 7

Time and space complexity

Time
O(log n)
Each iteration discards half of the active search range. An array of size n can be divided in half at most log₂ n times.
Space
O(1)
The iterative version only allocates constant space for tracking the left, right, and midpoint indices.

Common misconception

Binary Search is not limited to checking elements inside arrays. It applies to any monotonic space (e.g. range of bounds, sorted outputs, monotonic functions) to locate the first or last value satisfying a specific condition (often called 'binary search on the answer').
